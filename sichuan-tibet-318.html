ON THE ROAD / 318 川藏线之旅

从成都到拉萨，把路上的记忆留下

2023年7—8月，我从成都出发，全程骑行23天，最终到达拉萨。单车、同伴、山谷与湖泊，组成了这段旅程；去理塘途中的一次摔车，也改变了我后面的骑行节奏。

起点线索成都 · 成都理工大学抵达线索拉萨 · 布达拉宫完成方式全程骑行 · 23天行程时间2023年7—8月 · 23天为本人回忆 · 骑行期说说：7月21日—8月12日

目前整理的是下载中的部分照片；QQ空间地点列表显示“共84个景点”，其中含重复地点与校园日常，并不等于84个独立旅行站点。

旅程线索

成都出发 → 雅安／新沟 → 瓦斯沟／折多塘 → 折多山 → 雅江 → 理塘方向 → 巴塘 → 芒康／拉乌山 → 左贡／东达山 → 邦达 → 八宿／业拉山 → 然乌 → 波密 → 通麦 → 鲁朗／林芝 → 日多／米拉山 → 拉萨

这条阅读线索依据本人提供的地点列表与骑行经历编排，便于回看旅程；不是GPS轨迹，也不据此推定每段里程、骑行天数或实际道路。

  1. 01 / 出发前 · 成都

    地点记录中多次出现成都理工大学、二仙桥校区珙桐园，以及单车店和成都周边地点。它们作为出发前后的生活背景保留，不全部认定为318沿线站点。

  2. 02 / 旅程转折 · 去理塘的路上

    去理塘的路上，我摔了车。回想起来，那一次非常危险，差点没能平安继续这段旅程。此后，我选择慢慢骑，把安全放在前面。 从加油站、庄园、旅馆、客栈到餐馆，地点列表也留下了旅途的生活侧面。“中国石油雅江加油站”“美丽·雅江人民川菜馆”和“甘孜藏族自治州巴塘县”是这一段的明确地名线索；住宿和用餐是否实际发生、各停留日期仍待补充。

  3. 03 / 继续向前 · 左贡与邦达

    “左贡318快捷酒店”和“地区客运公司邦达运输站”保留了下一段行程的地点线索。照片里的单车、路牌与山谷公路可作为路上记忆，但暂不逐张绑定到某一站。

  4. 04 / 风景与停靠 · 然乌、通麦

    地点列表明确出现“然乌湖风景区”与“林芝市波密县通麦镇邮政局”。相册中也有湖泊和山谷画面；在逐张确认之前，湖景仍标为地点待核对，不直接认定为然乌湖。

  5. 05 / 接近终点 · 日多

    摔车之后，我放慢节奏，继续安全骑行。后续列表保留了“邦杰塘服务区”“日多卓玛茶馆”等名字。从这些小地点，可以继续补写补给、休息与相遇的细节；当前不编造天气、海拔、身体感受和骑行难度。

  6. 06 / 抵达与回望 · 拉萨

    23天全程骑行后，我最终到达拉萨。这段旅程最想留下的，不只是终点，还有摔车后慢慢骑、平安抵达的经历。“色拉小区”“布达拉宫”和“中国邮政(天上西藏邮局广场店)”构成抵达后的地点记录。可辨认的布达拉宫白天与夜景照片，成为这一页的收尾；列表随后再次出现成都理工大学，暂保留为旅程之后的校园记录线索。

按城市与县镇展开的旅记

城市足迹扩展到沿线县镇。地图点位仅方便浏览，不能用来计算我的真实里程或还原每一天的骑行轨迹。

雅安、新沟、康定 / 从雨天到折多山

7月21日的说说标题记录第一天骑到雅安；同日回复写全天有雨、准备骑到新沟。7月22日的两条说说分别写新沟与瓦斯沟，7月23日写折多塘，7月24日写登顶折多山。它们让前段行程有了原话与日期线索，但同日发表的不同“骑行天数”不能直接变成每日抵达表。

芒康、左贡、八宿 / 山口与藏东公路

7月31日的拉乌山说说与4376米路牌相互印证。本次新增东达山纪念碑、八宿墙面、业拉山说明牌与莲花广场合影，为藏东路段补上代表图。地名归入相应县级足迹，海拔只在可读牌面与原话中保留，不推算个人爬升或身体反应。

成都 / 骑行的起点

2023年7—8月，我从成都出发。全程骑行23天的经历从这里开始。此前提供的成都理工大学、单车店和校园地点，作为出发前后的生活背景；出发阶段现有说说作为证据，照片尚未充分匹配。

雅江、理塘 / 改变节奏的转折

沿途地点中有雅江加油站、餐馆与骑友之家等名字。去理塘的路上，我摔了车，那一次非常危险。之后我慢慢骑，把平安放在前面。当前不以任何一张普通路面照片冒充事故现场，也不推测伤情。

巴塘、左贡、邦达 / 继续前行

地点记录留下巴塘县、左贡318快捷酒店与邦达运输站，新增照片也补上东达山与拉乌山的地标。它们成为旅程中段的停靠线索；每天的里程与住宿顺序仍待补全；已有明确地名的照片独立进入对应县级足迹。地图先保留地点与记录入口。

然乌 / 湖泊记忆待逐张匹配

本人此前的地点列表明确出现然乌湖风景区。相册有多组湖泊画面，但当前下载批次包含大量林芝与拉萨段照片，不能把所有湖景都归到然乌。然乌点位先依据本人地点记录保留。

波密 / 藏王故里与沿途山谷

照片编号534有“藏王故里”入口，构成波密的地名线索。558附近的建筑标识不够清晰，继续保留待核对。明确证据照片已归入波密；周边云雾、树林与公路保留原编号，地点未确认的继续留待核对。

通麦 / 桥梁前后的路

320至361附近出现桥梁门架、吊桥与斜拉桥画面，其中可辨认通麦大桥标识。这组桥梁照片独立进入通麦足迹；邻近所有山景不因此自动划入同一个地点。

鲁朗 / 小镇、草地与路边记忆

408的塔体有“鲁朗小镇”，415及432附近有鲁朗纪念石，435有“鲁朗欢迎您”。这些明确地名照片组成鲁朗的核心记录。草地、单车、餐食和林间公路作为沿途内容保留，尚未定位的单独标注。

林芝 / 水印与八一镇线索

243附近的提示牌有八一镇署名，部分纪念建筑与合影带有林芝地点水印。它们作为林芝市范围的证据，暂不继续细分没有证据的村镇；其余湖泊、牦牛、云雾与公路按照片原顺序呈现。

日多、米拉山 / 接近拉萨

地点列表中有日多卓玛茶馆；179的石碑可直接读到米拉山口。举起单车的纪念照片与同一组地标照片归入墨竹工卡县级足迹，地图使用县城概略点位，不冒充米拉山垭口的拍摄坐标。

拉萨 / 23天后平安抵达

最终我骑到了拉萨。布达拉宫的白天、夜景与倒影，主题邮局、街头和与同行者相聚的画面，让终点有了具体的样子。这段旅程留给我的，不只是抵达，也是摔车后放慢节奏、一路平安继续的经历。
